# 从零学浏览器插件：5 课学习路线

> 适合完全没做过插件的小白。每课 5~15 分钟，**必须亲手操作**。
> 做完一课回来和 AI/老师讨论，再做下一课。

## 先建立一个心理模型：插件 = 一个小公司

| 角色 | 公司比喻 | 技术名词 | 能干什么 |
|---|---|---|---|
| **说明书** | 营业执照 | `manifest.json` | 告诉浏览器：我叫什么、有哪些员工、要什么权限 |
| **前台** | 门面 | popup / side panel（HTML 页面） | 用户能看到的界面 |
| **外勤** | 出差的员工 | content script | 被派到每个网页里，能摸网页的 DOM |
| **后台办公室** | 总部 | background service worker | 常驻后台，存数据、发指令 |
| **间谍** | 打入公司内部的人 | 注入脚本（MAIN world） | 混进网页自己的 JS 世界，偷看它真实的变量和请求 |

**一句话记忆**：插件就是把「网页前端」加上「一张说明书」，再让几个角色互相打电话（消息通信）。

## 5 课路线

| 课 | 学什么 | 产出 | 对应真实项目的哪部分 |
|---|---|---|---|
| [01](./01-hello-extension/) | manifest 是什么、怎么加载插件 | 点图标弹出一句话 | manifest + popup 骨架 |
| [02](./02-popup-storage/) | 弹窗里写 JS、数据持久化 | 一个记点击数的弹窗 | `chrome.storage` |
| [03](./03-content-script/) | content script 是什么、隔离世界 | 给网页加粉色边框 | content script |
| [04](./04-worlds-messaging/) | 四个角色打通消息链路、为什么需要注入脚本 | 弹窗里实时显示页面的秘密和请求 | injected/content/background 三件套 |
| [05](./05-real-project/) | 把 4 课概念映射到真实项目 | 看懂 api-inspector 全部代码 | 整个项目 |

## 每课开始前：怎么加载插件（通用操作）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「**开发者模式**」开关
3. 点左上角「**加载已解压的扩展程序**」
4. 选择本课的文件夹（注意：选**文件夹本身**，不是里面的文件）
5. 改完代码后，在扩展卡片上点「**刷新**」图标（↻）重新加载

## 怎么看日志（调试必备）

| 想看谁的日志 | 操作 |
|---|---|
| 弹窗的日志 | 点开插件弹窗 → 在弹窗上右键 → 「检查」 |
| 后台的日志 | `chrome://extensions` → 找到插件卡片 → 「Service Worker」链接 |
| content script 的日志 | 打开任意网页按 F12 → 「控制台」标签（和网页日志混在一起） |
| 报错 | 插件卡片上点「错误」按钮 |

## 学习建议

- 每课的 README 里有「✅ 检查点」和「💪 小练习」，小练习一定要做——改代码比看代码学得快 10 倍
- 报错不要怕，把报错信息原样贴出来，这是学习最快的材料
- 不要跳课，尤其是第 3 课（隔离世界）是后面一切的基础
